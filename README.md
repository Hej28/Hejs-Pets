# Hej’s Pets

Hej做的一个小玩具。把喜欢的照片变成会在 Mac 的 Dock 和屏幕边缘爬行的小宠物。现在处在能用的状态。Hej’s Pets 是一个轻量的原生 macOS 应用；照片处理和宠物资料都留在本机。

## 能做什么

- 拖拽入 JPG、PNG、HEIC 图片，或点击「选择照片」从文件夹添加；可以添加多只宠物、隐藏或删除。
- 自动识别人脸；需要调整时可选择「矩形范围」或「自由圈选」，并用涂抹、橡皮擦修正边缘。
- 自动检测衣服，或圈选一块衣料作为身体纹理。
- 让宠物沿 Dock 或屏幕四周爬行，也可选跳跃、舞蹈或随机动作；拖拽时会有互动反馈。
- 自定义气泡文字、出现间隔、五官表情定位和动画帧率。

## 开始使用

1. 在 [Releases](https://github.com/Hej28/Hejs-Pets/releases) 下载适合 macOS 的安装包；也可以按下文从源代码构建。
2. 打开 Hej’s Pets，把照片拖进「放一张照片进来」区域，或点击「选择照片」。
3. 在宠物卡片中调整头部裁切、衣服材质与显示状态；在「互动设置」中选择动作、气泡和帧率。
4. 要暂停、隐藏或退出，可用主窗口底部的按钮，或点屏幕顶部菜单栏的「Hej’s Pets」。关闭主窗口也会退出应用。

> 首次打开未经 Apple 公证的构建包时，macOS 可能要求在「系统设置 → 隐私与安全性」中确认。请仅运行你信任来源的版本；自行构建也是一种选择。

## 隐私与照片

不会把照片上传到服务器，也不需要账户。导入时会在以下本机目录保存供宠物使用的副本和设置：

```text
~/Library/Application Support/HejPets/
```

在应用中删除宠物只删除应用保存的副本，不会删除你原来的照片。提交问题报告时，请不要附上含真人照片的运行数据或截图，除非你明确愿意公开它们。仓库的构建产物、缓存、运行日志和私人修复备份均被 `.gitignore` 排除。

## 从源代码构建

要求：macOS 13 或更高版本、Apple Silicon Mac、Xcode Command Line Tools。项目使用 AppKit、Core Image 和 Vision，不依赖第三方库。

```bash
./build.sh
```

构建结果在 `build/HejsPets.app`。脚本使用临时签名；若要面向其他人正式分发，请自行使用 Apple Developer ID 签名并完成公证。
